# 🎵 Audio Volume Analyzer

## 📌 Project Description

Audio Volume Analyzer is a simple Python project that analyzes the volume level of an audio file. It calculates the average and maximum volume and classifies the audio as **Low, Medium, or High**.

The project also displays the audio waveform using a graph.

## 🛠️ Technologies Used

* Python
* Google Colab
* Librosa
* NumPy
* Matplotlib

## ✨ Features

* Upload `.wav` or `.mp3` audio files
* Calculate average volume
* Calculate maximum volume
* Detect volume level
* Display audio waveform
* Simple and beginner-friendly interface

## ▶️ How to Run

1. Open **Google Colab**.
2. Create a new notebook.
3. Paste the project code.
4. Run the code.
5. Upload an audio file.
6. View the volume analysis and waveform.

## 📊 Output

The program displays:

```text
===== AUDIO ANALYSIS =====
File: sample.wav
Sample Rate: 44100 Hz
Average Volume: 0.0834
Maximum Volume: 0.4215
Volume Level: Medium
```

It also generates a waveform graph showing how the audio volume changes over time.
